# Japanese Data Pipeline
Lightweight script that takes user input, tokenizes words, and matches their definitions and readings to a database.

Workflow: Return word definitions, extract all kanji, and define them in a tree view. 

Input: Accepts standard input and pipes it to the script, then prints all necessary information.

# Issues
Currently the database has no API, so only users with access to the repository can see what is inside of the project. Users without access can only see the current code.
